# A changed quality band keeps one home

The owner tightens a latency band. The fixture restates the old number beside the Q- item, in
the part's budgets and the architecture's observability line. The new number must live only in
the Q- item; the old one disappears and the part cites Q-01 instead of restating it. Assertions
grep the spec files the kit's own helpers list; human review checks the wording.
